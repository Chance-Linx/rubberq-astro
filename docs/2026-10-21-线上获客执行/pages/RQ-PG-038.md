## 英文页面稿

# O-Ring Size and Drawing Guide

Prepare the dimensions needed for an O-ring review. Record the inside diameter, cross-section, groove and mating-part dimensions together with the service conditions.

## Identify the size reference

Include the reference system and exact size code when available. For a custom part, provide a dimensioned drawing rather than a photograph alone.

## Check the installed geometry

Groove dimensions, stretch, squeeze and clearance affect the seal. The component dimensions need to be reviewed with the assembled condition.

## Send a useful request

Attach the drawing revision, material designation, quantity and operating conditions. Size identification is the starting point for review, not a performance qualification.

## Discuss the Specification

Contact RubberQ at contact@rubberq.com or submit the project form with your drawing, service conditions and quantity.
