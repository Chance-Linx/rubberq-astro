# 第二批正文审读与质量文章修订

目的：继续落实已批准的获客规划，完成源索引50–99的全文审读，将质量与工程主题中缺少依据的公开说法转为可执行的改稿要求。全项目完成后再集中审核。

## 本轮实际成果

- 新增50篇全文审读，累计100/271。每篇包含买家任务、原URL、正文定位、源revision与content规范序列hash、问题、修订要求和拟连接商业父页。
- 本批提案：31篇保留原URL重写、10篇转为条件明确的技术参考、9篇核对业务范围。累计提案：62重写、16参考重写、21核对范围、1保留优化。
- 新增O圈外观验收及橡胶质量偏差8D两篇同URL英文正文，分别578与608个可见词。累计四份修订稿，仅提案title/excerpt/content，原slug、日期、状态、分类、作者与图片不随稿件变更。
- 看板生成数据已接入100条审读记录，CSV与JSON保持一致。原始271篇正文快照未改写。

审读记录见 [[reviews/batch-002.json]]、[[reviews/存量正文审读与处置提案.csv]]。文内提及的“第N篇”均指原始快照零起算的source_index，不代表文章发布日期顺序。

## 本轮对改稿有影响的发现

| 源索引 | 具体正文问题 | 后续处理 |

| 83 | 通用缺陷尺寸、23%失效占比、100%尺寸检查与QR证明没有对应依据 | 已准备外观验收稿，不从公开摘要杜撰完整标准限值 |
| 84 | 公开写“we comply with AS9100 requirements”，当前事实库没有该体系依据 | 核对范围；不能以材料温区或IATF代替航空体系证明 |
| 85 | NACE MR0175标题被用于橡胶材料排名 | 公开ISO15156范围针对金属材料，不能据此证明橡胶配方符合 |
| 86–89 | FMEA、控制计划、8D、MSA标题下仍大量重复物性表；RFID、量具精度、固定校准、Cpk值和客户案例缺记录 | 分别回到风险、关键特性、问题闭环和量测任务；8D稿已准备 |
| 94、99 | 空洞与欠注没有工艺排查，靠材料家族表和“消除变异”解释 | 区分内部空洞与未充满，补模具、胶料及成型对照记录 |

上述是当前保存正文与资料之间的证据缺口，不是对工厂实际能力不存在的判断。HOLD_SCOPE也不是删除、下线或禁止承接客户需求的决定。

## 两份新增英文修订

### O圈外观验收

[[content-revisions/o-ring-visual-inspection.html]] 对应源索引83。新题目为 `O-Ring Visual Inspection: Specify Acceptance with ISO 3601-3`。

正文说明询价应明确的标准、版次、等级和图纸要求，列出观察记录、带比例照片、批次及数量信息，区分来料状态与安装/服役后损伤。删除无出处失效占比与通用缺陷尺寸，没有把公开摘要替代完整标准，也未承诺RubberQ已实施特定检查比例。

### 质量偏差与8D

[[content-revisions/rubber-quality-deviation-8d.html]] 对应源索引88。新题目为 `Rubber Part Quality Issues: Prepare an 8D Review`。

正文围绕零件、批次、要求、受影响范围、样品与使用历史组织问题，区分观察与猜测、临时措施与永久纠正、原因与漏检原因、试验结果与服役效果。去掉未证实客户案例和配方性能。方法说明不是RubberQ已完成某客户8D的案例宣传。

两稿的原revision、hash、拟修改字段和发布前依赖见 [[content-revisions/manifest.json]]。均未写入CMS。

## 一手资料与使用范围

本轮追加4项公开一手索引到 [[reviews/primary-references.json]]：

- [ISO 3601-3公开摘要](https://www.iso.org/standard/40409.html)：确认O圈表面缺陷及验收的标准范围；具体限值仍由适用完整标准与项目规格核对。
- [ISO 15156-1:2020公开范围](https://www.iso.org/obp/ui?_escaped_fragment_=iso%3Astd%3Aiso%3A15156%3A-1%3Aed-4%3Av1%3Aen)：确认金属材料适用对象，不用它为弹性体背书。
- [AIAG质量核心工具公开简介](https://www.aiag.org/expertise-areas/quality/quality-core-tools)：确认设计/过程FMEA任务，不复制评分表或声称自有项目执行结果。
- [ASQ的8D说明](https://asq.org/quality-resources/eight-disciplines-8d)：核对方法组织，正文用自写的橡胶采购情境表述，不引入未验证工厂案例。

没有购买、取得或复现付费标准全文，没有新增付费数据调用。
