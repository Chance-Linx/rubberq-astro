# 27篇文章真实布局与封面处理

目的：让27篇完整修订稿可以在正式网站版式中审读，并处理旧封面与正文不一致、手机表格撑宽页面的问题。本文记录本地实施结果；全项目集中审核仍未开始。

## 已完成的本地结果

- 原 `/blog/[slug]` 的呈现部分抽为 `src/components/blog/ArticlePage.astro`，普通文章与本地修订稿共用。原路由的CMS获取、canonical slug、计划发布时间及不可用状态逻辑保留。
- 专用本地配置通过 `npm run review:articles` 启动。入口为 <http://127.0.0.1:4398/__review>，27篇文章仍沿原slug阅读；在该端口点击正文中的文章链接继续显示修订稿，点击产品/材料/联系页进入真实网站组件。
- 27篇正文、146条正文链接、27张表格逐项与本地稿比对通过；其中113条站内正文链接仍为30条稿间和83条页面链接，另有33条来源外链。日期、标题、摘要、schema及正式canonical均核对。
- 表格保留原单元格、单位、表头与链接，增加可键盘聚焦的横向滚动容器；手机页面本身不会被表格撑宽。无图的相关文章卡片采用完整文字布局，移除空灰色图框。

## 19张旧封面与8篇无封面

本轮重新以只读方式取回27条CMS元数据，27个版本号均与正文快照一致。19篇有封面引用，8篇没有引用；不能把旧正文快照未选取的字段视为没有封面。

19张现存封面已在原比例画廊逐图检查，全部在候选呈现层隐藏。主要问题是重复皮具/木质工具台库存画面、发动机画面、通用模压宣传图与具体工程任务不相符，以及图中嵌入旧“3倍成本”“预测失效”“汽车级”等表达。逐篇理由、原asset引用和来源版本见 [[evidence/article-cover-decisions.json]]，原图截图见 `evidence/article-cover-sheet-1.png` 至 `5.png`。

隐藏规则只匹配已审读的文章ID与原asset引用组合。CMS封面字段、图片文件均未删除或改写；替换为新图片后不会自动继承旧决定。8篇原本无封面的文章维持文字与参数表布局。没有为补图生成工厂、测试或性能证明。

文章封面、OG/Twitter图片与BlogPosting图片采用同一决定，避免正文已隐藏而分享信息继续出现旧图。博客列表的封面与展示仍在后续专用页面任务中处理。
