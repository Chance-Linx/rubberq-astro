# 2026-05-12 媒体资产位清单（图片 + 视频）

> 第 4 步实施期间所有页面的占位规范。用户审核后用真实素材替换。
>
> **占位约定**：每个占位在代码里写成统一格式的 `<div>`，含 `data-slot-id`、`data-purpose`、`data-spec`、`data-priority` 四个属性。审核时按 ID 对应替换。

## 占位代码约定

所有图片/视频占位统一使用如下模式（在 .astro 文件里）：

```astro
<div
  class="bg-industrial-100 border-2 border-dashed border-industrial-300 aspect-video flex flex-col items-center justify-center p-6 text-center"
  data-slot-id="hero-factory-aerial"
  data-purpose="工厂全景航拍"
  data-spec="1920x1080 横向 / 视频 ≤8s 循环"
  data-priority="critical"
>
  <span class="text-xs uppercase tracking-widest text-industrial-500 mb-2">
    PLACEHOLDER · hero-factory-aerial
  </span>
  <span class="text-sm text-industrial-700">工厂全景航拍 · 1920x1080</span>
  <span class="text-xs text-industrial-500 mt-2">用户审核后替换</span>
</div>
```

- **data-slot-id**：唯一槽位 ID（kebab-case），跨页面唯一
- **data-purpose**：用途一句话说明
- **data-spec**：尺寸 / 时长 / 风格
- **data-priority**：critical（影响转化）/ important（增强信任）/ nice-to-have（锦上添花）

## 转化重要度评级（priority）

- **critical**（红色）：直接影响首屏停留与询盘转化。**必须真实素材**，不能用 stock photo
- **important**（黄色）：技术信任证据，最好真实素材，必要时可用高质量行业图
- **nice-to-have**（绿色）：装饰性，stock photo 也可接受

## 用户审核交付物建议

为方便用户对齐素材，建议你审核时按以下结构准备一个 `assets/` 文件夹：

```
assets/
├── critical/                  # 17 张 critical 优先级
│   ├── home-hero-bg.jpg
│   ├── home-industries-ev.jpg
│   ├── compounding-aline-machine.jpg
│   ├── ...
├── important/                 # 38 张 important
│   └── ...
├── nice-to-have/              # 12 张 nice-to-have
│   └── ...
├── videos/                    # 5 段视频
│   ├── home-hero-video.mp4
│   ├── about-corporate-video.mp4
│   ├── compounding-hero-video.mp4
│   ├── compounding-video-process.mp4
│   └── factory-promo-video.mp4
└── certificates/              # 证书扫描件
    ├── quality-cert-iatf.pdf
    └── ...
```

实施时所有占位会保留 `data-slot-id` 属性，方便后续批量替换脚本：

```bash
# 伪代码：审核完素材后批量替换
node tools/replace-placeholders.js \
  --asset-dir ./assets \
  --target ./src/pages \
  --upload-to r2://images.rubberq.com
```
