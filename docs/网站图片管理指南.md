# 网站图片管理指南

> 本文档说明如何更新网站中的图片，包括上传到 R2 CDN 和替换代码中的占位图。

---

## 一、图片存储位置说明

| 存储位置 | 用途 | 访问地址 |
|----------|------|----------|
| **Cloudflare R2** | 博客特色图、工厂实拍照 | `https://images.rubberq.com/` |
| **public/images/** | 产品图、Logo、图标 | `/images/xxx.jpg` |
| **Unsplash（临时）** | 占位图，需替换为实拍 | `https://images.unsplash.com/...` |

---

## 二、上传图片到 R2

### 2.1 准备工作

1. 确保 `.env` 文件中有以下配置：
   ```
   R2_ACCOUNT_ID=xxx
   R2_ACCESS_KEY_ID=xxx
   R2_SECRET_ACCESS_KEY=xxx
   R2_BUCKET_NAME=rubberq-images
   R2_PUBLIC_URL=https://images.rubberq.com
   ```

2. 准备好图片，建议：
   - 格式：JPG 或 WebP（WebP 更小）
   - 尺寸：根据用途选择（见下表）
   - 命名：英文小写，用连字符分隔，如 `workshop-overview.jpg`

### 2.2 推荐图片规格

| 用途 | 推荐尺寸 | 格式 | 最大大小 |
|------|----------|------|----------|
| 首页 Hero 大图 | 1920×1080 | WebP | 500KB |
| 工厂/设备照片 | 1200×800 | WebP/JPG | 200KB |
| 产品图 | 800×600 | WebP/JPG | 100KB |
| 博客特色图 | 1792×1024 | JPG | 100KB |
| 证书扫描件 | 800×1100 | PNG | 300KB |

### 2.3 上传命令

```bash
# 进入项目目录
cd /Users/LINLAN/1\ 赚钱事业/外贸跨境项目/2025年项目/2024-03-02\ 橡胶独立站/RubberQ-B2B-Site

# 上传整个文件夹
node tools/upload-to-r2.mjs ./你的图片文件夹/ 目标文件夹名

# 示例：上传工厂照片到 factory/ 目录
node tools/upload-to-r2.mjs ./factory-photos/ factory

# 示例：上传质检照片到 quality/ 目录
node tools/upload-to-r2.mjs ./quality-photos/ quality

# 示例：上传单个文件
node tools/upload-to-r2.mjs ./workshop.jpg factory
```

### 2.4 上传结果

脚本会输出所有上传成功的 URL：

```
https://images.rubberq.com/factory/workshop-overview.jpg
https://images.rubberq.com/factory/injection-molding.jpg
https://images.rubberq.com/factory/quality-lab.jpg
```

**保存这些 URL**，下一步替换代码时需要用到。

## 三、替换网站中的占位图

### 3.1 需要替换的页面

| 页面 | 文件路径 | 需要的图片类型 |
|------|----------|----------------|
| **Factory 工厂** | `src/app/[locale]/factory/page.tsx` | 车间、设备、生产线（约 10 张） |
| **Quality 质量** | `src/app/[locale]/quality/page.tsx` | 检测设备、证书、质检流程（约 8 张） |
| **Case Studies 案例** | `src/app/[locale]/case-studies/page.tsx` | 客户案例产品（3 张） |
| **首页** | `src/app/[locale]/page.tsx` | 行业应用场景（3 张） |

### 3.2 替换步骤

1. **打开对应文件**，搜索 `unsplash.com`

2. **找到图片 URL**，类似：
   ```tsx
   image: 'https://images.unsplash.com/photo-1565043666747-69f6646db940?auto=format&fit=crop&q=80&w=800'
   ```

3. **替换为 R2 URL**：
   ```tsx
   image: 'https://images.rubberq.com/factory/workshop-overview.jpg'
   ```

4. **保存文件**

5. **提交并推送**：
   ```bash
   git add .
   git commit -m "update: replace placeholder images with factory photos"
   git push origin main
   ```

6. **等待 Cloudflare 自动部署**（约 1-2 分钟）

### 3.3 代码示例

**替换前（Unsplash 占位图）：**
```tsx
const facilities = [
  {
    title: "Rubber Mixing Workshop",
    image: 'https://images.unsplash.com/photo-1565043666747-69f6646db940?auto=format&fit=crop&q=80&w=800',
    // ...
  }
];
```

**替换后（R2 实拍照片）：**
```tsx
const facilities = [
  {
    title: "Rubber Mixing Workshop",
    image: 'https://images.rubberq.com/factory/mixing-workshop.jpg',
    // ...
  }
];
```

## 五、常见问题

### Q1: 上传失败怎么办？
检查 `.env` 文件中的 R2 配置是否正确，特别是 `R2_ACCESS_KEY_ID` 和 `R2_SECRET_ACCESS_KEY`。

### Q2: 图片太大怎么压缩？
推荐使用 [TinyPNG](https://tinypng.com/) 或 [Squoosh](https://squoosh.app/) 在线压缩。

### Q3: 如何查看已上传的图片？
登录 Cloudflare Dashboard → R2 → rubberq-images bucket，可以浏览所有已上传的文件。

### Q4: 图片上传后多久生效？
立即生效，R2 是 CDN 存储，全球访问。

### Q5: 可以删除 R2 中的图片吗？
可以，在 Cloudflare Dashboard 的 R2 管理界面中删除，或使用 AWS CLI。
