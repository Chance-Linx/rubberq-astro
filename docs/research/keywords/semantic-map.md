# SEO Semantic Map & Page Layout Strategy

To maximize the SEO value of the gathered technical knowledge, the website should follow a "Hub-and-Spoke" model centered around the **Tank Pages** (Core Topic Pages).

## 1. Core Topic Cluster: Automotive Grade Reliability
- **Main Keyword**: "Automotive Rubber Components Manufacturer"
- **Semantic Links**:
    - "IATF 16949 Certified Factory" (Trust)
    - "PPAP Documentation for Rubber Parts" (Process)
    - "Zero-Defect Quality Culture" (Benefit)
- **Target Page**: Home Page / "Why Us" Page.

## 2. Technical Cluster: Material Excellence
- **Main Keyword**: "High Performance Rubber Materials"
- **Semantic Links**:
    - "FKM Chemical Resistance Chart" (Research Intent)
    - "EPDM vs Silicone for Automotive Seals" (Comparison Intent)
    - "ASTM D2000 Classification Guide" (Educational/Authority)
- **Target Page**: "Materials" Tank Page.

## 3. Capability Cluster: Custom Manufacturing
- **Main Keyword**: "Custom Rubber Molding Services"
- **Semantic Links**:
    - "Precision Injection Molding" (Specific Process)
    - "Overmolding Rubber to Metal" (Technical Solution)
    - "Rapid Prototyping for Rubber Gaskets" (Service Speed)
- **Target Page**: "Manufacturing Capabilities" Page.

## 4. User Intent Mapping
| Search Query | Search Intent | Recommended Content Type |
| :--- | :--- | :--- |
| "rubber parts factory fuzhou" | Transactional / Navigational | Factory Profile / Contact Page |
| "FKM seal temperature range" | Informational / Technical | Technical Specs Table in Material Page |
| "IATF 16949 rubber supplier checklist" | Informational / High Trust | Blog Post / Whitepaper |
| "custom EPDM hose manufacturer" | Transactional | Service Landing Page with RFQ Form |

## 5. Inner-linking Strategy
- Every **Material Detail** should link to a relevant **Process Page** (e.g., "FKM" -> "Vacuum Vulcanization").
- Every **Technical Article** (Blog) should lead to the **RFQ (Request for Quote)** button.
- **Certification Badges** must be clickable, leading to a dedicated "Quality Standards" page.
