# 2026-05-14 关键词调研 v2（高意向词 Top 50）

> 替代 `core-keywords.csv` 与 `semantic-map.md` 中的 v1 体系。v1 偏 auto-grade generalist 叙事，v2 重做以匹配新画像（小批量精密配方件 + 日本研发 + 中国精密 + EV 重仓）。
>
> **方法**：三维度分层，每层按 Funnel Stage 排序。优先抓"意向度 × 稀缺度"双高的长尾词，而非头部短词。chat 原话："R&D / Compounding 类高意向词搜索量小，但意向度高 5-10 倍。"

## 方法论

### 三维度（按价值倒序）

| 维度 | 解释 | 客户场景 | 落地页 |
|---|---|---|---|
| **A. R&D / Compounding 驱动**（最高价值） | 工程师有"材料瓶颈"，找联合开发伙伴 | 场景 B（应用驱动询盘） | /compounding |
| **B. 行业 Application 驱动** | 工程师有应用，找懂这个应用的供应商 | 场景 A+B 混合 | /industries/* |
| **C. 产品 Spec / 标准驱动** | 采购拿着图纸找供应商比价 | 场景 A（图纸驱动 RFQ） | /products, /materials, /testing |

### Funnel Stage

- **TOFU**（Top of Funnel）— 教育型搜索，工程师在学
- **MOFU**（Middle）— 比较 / 评估供应商
- **BOFU**（Bottom）— 准备询盘 / 报价

### Difficulty 估算

主观分级（无 SEMrush/Ahrefs 实测，等上线后用数据校准）：
- **L** = Low — 长尾、专业、竞争少（5 个月内有机会上首页）
- **M** = Medium — 中等竞争（6-12 个月）
- **H** = High — 头部短词，竞争激烈（短期不打）
