# RubberQ Project Research & Knowledge Base

本项目文档库用于存储 RubberQ 外贸独立站建设初期的所有调研成果与技术知识图谱。

## 目录结构说明

- `/competitors/`: 存储全球顶级橡胶零部件供应商的调研报告。
    - `analysis-summary.md`: 综合分析报告。
    - `/profiles/`: 存放各竞品的详细档案。
- `/knowledge-graph/`: 结构化的橡胶行业技术知识。
    - `materials.json`: 核心橡胶材质特性数据库。
    - `processes.md`: 生产工艺与质量控制流程。
    - `standards.json`: 国际标准（ASTM, ISO）与 IATF 16949 关键节点。
- `/keywords/`: SEO 关键词与语义分析。
    - `core-keywords.csv`: 基于调研提取的核心出口关键词。
    - `semantic-map.md`: 针对搜索意图的页面布局规划建议。

## 更新规范
1. 所有调研文档需采用英文为主（外贸出口导向），关键术语需保留中英对照。
2. 数据格式优先使用 JSON 存储，以便后续自动化集成。
