## 2026-02-28 项目信息更新

### 一、项目背景

**公司名称**：福州 RubberQ 橡胶有限公司  
**业务性质**：大型橡胶工业零部件制造商；日系汽车品牌长期OEM供应商  
**成立时间**：1995年6月（中日合资企业，由日本J&C株式会社投资）  
**地理位置**：中国福建省福州市（港口通达 + 发达的铁路/公路基础设施 + 专业技术人才储备充足）  
**生产设施**：拥有2座生产厂区，总占地面积约20,000平方米，绿化率达30%  
**核心能力**：全流程橡胶制造与质量管控体系——覆盖配方研发、量产制造到成品检测全环节

### 二、建设目标

1. **全球品牌信任窗口**（展示品牌公信力 + 工厂硬实力）
2. **商机线索生成引擎**（承接报价咨询、样品申请、技术对接需求）
3. **长效SEO资产载体**（搭建行业知识库 + 布局符合搜索引擎结果页规则的"主题权威页面"）

**核心成果目标**：
- 持续获取精准询盘，转化为覆盖更多国家、更多行业、更高价值客户的实际出口订单
- 拓展精密制造行业：AI机器人、精密设备、医疗、食品级硅胶垫片等

### 三、技术架构

采用 **Headless 前后端分离架构**：

| 层级 | 技术栈 | 部署平台 |
|------|--------|----------|
| 前端 (Frontend) | Next.js 16 + React 18 + TypeScript | Cloudflare Pages |
| 后端 (CMS) | WordPress REST API | manager.rubberq.com |
| 逻辑层 (Serverless) | Cloudflare Workers | 处理RFQ表单提交 |
| 数据库 (DB) | Cloudflare D1 | 存储询盘数据 |
| 自动化 | Node.js 脚本 + OpenRouter API | AI批量生产文章 |

### 五、核心模块说明

**1. 国际化 (i18n) 模块**
- 技术方案：next-intl v4 + Next.js 15 App Router
- 翻译文件位置：`src/messages/{en,de,ja,es,zh}.json`
- 路由中间件：`src/middleware.ts`
- 动态布局：`src/app/[locale]/layout.tsx`

**2. 博客内容管理模块**
- 数据源：WordPress REST API (`https://manager.rubberq.com/wp-json/wp/v2`)
- 文章抓取：`src/lib/blog.ts`
- 文章列表页：`src/app/[locale]/blog/page.tsx`
- 文章详情页：`src/app/[locale]/blog/[slug]/page.tsx`
- 特色图片：自动抓取并优化

**3. 询盘 (RFQ) 处理模块**
- 前端表单：`src/components/contact/ContactForm.tsx`
- API端点：`https://rubberq-rfq-api.midnightblue-lin.workers.dev`
- 数据存储：Cloudflare D1 数据库
- 邮件通知：Resend API 发送至 contact@rubberq.com

**4. SEO优化模块**
- 动态 Sitemap：`src/app/[locale]/sitemap.ts`
- Robots.txt：`src/app/[locale]/robots.ts`
- 结构化数据：JsonLd 组件
- Google Analytics：`src/components/GoogleAnalytics.tsx`
- 滚动追踪：`src/components/home/ScrollTracker.tsx`

**5. 图片优化模块**
- 组件：`src/components/OptimizedImage.tsx`
- 特性：懒加载、WebP/AVIF格式、blur placeholder、响应式 sizes

**6. 认证展示模块**
- 证书灯箱：`src/components/CertificateLightbox.tsx`
- 质量页面：`src/components/quality/QualityPageClient.tsx`
- 证书状态：active/expiring/expired 自动标记

2. **完善的制造基础设施** — 全自动原料称重、密炼/混炼设备、条码管理、ERP追溯

## 2026-02-28 页面级信息补充（用于执行落地）

### 一、首页（`/[locale]/`）

**页面目的**
- 快速建立信任感与工业级专业形象
- 引导用户进入技术内容（Blog）和质量页面（Quality）

**关键区块**
- Hero：三行主标题、双CTA（Technical Hub / Quality & Trust）
- Features：四大能力卡片 + 技术摘要组件 `SummarySnippet`
- Industries：三行业入口，指向具体技术博客文章

**关键组件**
- `src/components/TrackableButton.tsx`
- `src/components/home/ScrollTracker.tsx`
- `src/components/OptimizedImage.tsx`

### 二、产品中心（`/[locale]/products`）

**页面目的**
- 以材料与应用场景组织产品能力，支持询盘转化

**当前结构**
- Hero + 认证条
- 4类产品卡（seals/gaskets/bellows/custom）
- Custom Engineering 区块
- 下载资源区块（技术资料入口）

**已识别机会**
- 当前无产品详情路由（建议新增 `/products/[slug]`）

### 三、材料中心（`/[locale]/materials` + `/[locale]/materials/[slug]`）

**页面目的**
- 提供材料选型与参数比较，承接技术检索流量

**当前结构**
- 材料卡片（FKM/EPDM/NBR/Silicone）
- Comparison Matrix 参数对比
- 与资源中心的交叉链接

### 四、制造能力（`/[locale]/capabilities`）

**页面目的**
- 展示从原料到出货的全流程制造控制能力

**当前结构**
- 五阶段流程图（phase1~phase5）

- 页脚技术承诺区（Defect Tolerance）

### 五、工厂页面（`/[locale]/factory`）

**页面目的**
- 通过规模、区位、设备与流程证明交付能力

- 质量流程模块

### 六、质量页面（`/[locale]/quality`）

**页面目的**
- 作为信任核心页面，展示认证、检测与追溯体系

**当前结构**

- 实验室能力与检测场景
- 追溯流程可视化
- 引导到资源页面下载文档
